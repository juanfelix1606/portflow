# PortFlow

Container Terminal Operations & Financial Management System.

Aplikasi web simulasi manajemen operasional terminal peti kemas yang mengintegrasikan
aktivitas kontainer (gate in/out, tracking) dengan administrasi keuangan (invoice, pembayaran).

Proyek ini independen untuk pembelajaran dan portofolio. Seluruh data adalah data simulasi.

## Tech Stack

- Backend: Python 3.13, FastAPI, SQLAlchemy, Alembic, Pydantic
- Database: PostgreSQL
- Frontend: React, Vite, Tailwind CSS (direncanakan)
